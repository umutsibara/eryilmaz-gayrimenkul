# ERYILMAZ GAYRİMENKUL - Modern & Minimalist Emlak Web Sitesi

Manisa / Turgutlu'da hizmet veren **Eryılmaz Emlak Gayrimenkul Danışmanlığı** için sıfırdan tasarlanmış modern, sade, hızlı ve kullanıcı odaklı emlak listeleme web platformu.

🌐 **Canlı Demo**: [https://umutsibara.github.io/eryilmaz-gayrimenkul/](https://umutsibara.github.io/eryilmaz-gayrimenkul/)

---

## 🚀 Öne Çıkan Özellikler

- **Sade & Minimalist Tasarım**: Kullanıcının dikkatini dağıtmayan, fotoğrafları ve ilan detaylarını tek bakışta anlaşılır kılan ferah arayüz.
- **Anlık Canlı Filtreleme & Arama**:
  - Satılık / Kiralık tek tıkla durum geçişi
  - Kategori seçimi (Daire/Konut, Arsa & Bahçe, İşyeri & Ticari, Tarla & Arazi)
  - Mahalle bazlı konum filtresi
  - Dinamik anahtar kelime arama motoru
  - Fiyata ve tarihe göre anında sıralama
- **İnteraktif İlan Detay Modalı**:
  - Yüksek çözünürlüklü fotoğraf galerisi ve küçük önizleme şeridi
  - İlan metrekare (m²), oda sayısı, kat, tapu durumu vb. tüm teknik detaylar
  - Tek tıkla doğrudan ilan başlığı ile hazırlanmış hazır WhatsApp mesajı
  - Tek tıkla yetkili danışmanı (Muzaffer Eryılmaz) arama
  - Web Share API ile ilanı tek tıkla paylaşma veya bağlantısını kopyalama
- **Mobil ve Masaüstü Uyumlu**: %100 responsive, her ekran boyutuna göre optimize edilmiş esnek ızgara.
- **Sıfır Dış Bağımlılık (Ultra Hızlı)**: Ağır framework kütüphaneleri olmadan saf CSS3 ve Vanilla JavaScript ile 0 milisaniye gecikmeyle çalışır.
- **Kurumsal Güven Unsurları**: T.C. Ticaret Bakanlığı Taşınmaz Ticareti Yetki Belgesi No: **4500306** ve 8 yıllık deneyim vurgusu.

## 🛠️ Yerel Olarak Çalıştırma

Projeyi çalıştırmak için herhangi bir derleme (build) veya paket yüklemesine gerek yoktur:
1. `index.html` dosyasına çift tıklayarak doğrudan tarayıcınızda açabilirsiniz.
2. Ya da VS Code Live Server / Python ile:
   ```bash
   python3 -m http.server 8080
   ```
   ve `http://localhost:8080` adresini ziyaret edin.
